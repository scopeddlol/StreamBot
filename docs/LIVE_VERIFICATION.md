# StreamBot TV operator verification

These live checks require the operator's accounts, permissions, media rights and infrastructure. Automated fixtures are not proof of Discord/Jellyfin/Silo delivery.

1. Back up existing data and legacy token/config files without deleting media. Check out `feat/jellyfin-silo-integration`; run `docker compose up -d --build`. Open localhost and claim the admin with the one-time local-log pairing code. Confirm no `.env` or account token was needed to boot.
2. Verify protected metadata rejects unauthenticated access, `admin/admin` fails, pairing cannot replay, unsafe Origin requests fail, and sessions persist across restart. Configure HTTPS/trusted proxy before non-local credential entry; check Secure/HttpOnly/SameSite cookies.
3. Use browser legacy-file import if upgrading. Verify stable provider IDs, all old files unchanged, and any imported account remains stopped with risk acknowledgement off. Verify existing local video/cache paths remain present.
4. Add/test actual Jellyfin and Silo connections. Record server releases and Silo's compatibility listener/profile privately. Validate accessible libraries, TV navigation, media versions, artwork, paging and revoked/expired credentials. Do not assume native Silo keys/profile headers work on compatibility routes.
5. Configure the official command application, install it only in entitled guilds, start it and verify command registration. Test real role refresh/revocation, cross-guild denial, ephemeral selection, duplicate-title disambiguation, room selection, approval, quota/cooldown, own cancellation and staff controls.
6. Configure six live and two on-demand playback instances in the same panel. Choose distinct entitled accounts and destinations for concurrent video. Verify the experimental account warning and that official bot tokens fail clearly for native video. Start/stop/restart each independently and test Join/Move permissions with both allowed and inaccessible destinations.
7. Play a real Jellyfin movie and a real Silo episode. Verify moving video AND audible audio in Discord. No successful live stream has been established by the automated suite. Test a missing/broken file, mixed local/YouTube/Twitch/provider sources and cleanup after skip/stop.
8. Build a playlist with ten movies and a full season. Verify sequential/shuffle, off/one/all, cycle boundary, removal/reorder while playing, saved duplication/selection, reference import/export and play-now interruption. Restart during a program: the interrupted item should restart from its beginning, preserving the channel cursor. Check broken items retry/advance without a tight loop.
9. Stop during negotiation and actual FFmpeg streaming; terminate the container with multiple workers. Inspect processes, voice sessions and provider grants for cleanup. Test a worker crash and bounded restart, duplicate tokens/accounts, resource caps and a ninth worker after raising the cap. Force-killed sessions may require the provider's idle cleanup.
10. Let queued grants expire before their turn and verify fresh negotiation. Test an initially expired root grant. Midstream HLS grant expiration may be a controlled error/retry; seamless resume is unsupported.
11. Rotate and revoke credentials, edit one provider while another streams, and verify unrelated playback is unaffected. Inspect DB, public APIs, HTML, audit events and subprocess arguments privately for plaintext leaks. Keep `/data/security` owner-only. Never paste production logs or credentials into public test records.
12. Export an encrypted backup, retain its passphrase separately, stop all connections, and test an explicit restore in a disposable deployment. Confirm accounts/settings restore, sessions revoke, and media files remain separate. Do not test destructive restore against your sole production copy.
13. If AI is enabled, test a compatible model, budget/rate errors, private-endpoint opt-in, real catalog-only suggestions, hostile metadata and permission denial. Confirm no queue mutation happens without an ordinary authorized confirmation. Disable AI and verify core playback still works.
14. Record sustained CPU/RSS, encoder and audio/video quality for 2/4/8 actual streams on the target host. Synthetic 160×90 fixtures are not a capacity guarantee. Verify optional GPU mappings manually; software encoding is the default. Do not expose host devices or widen network access automatically.

Record deployed versions and each pass/fail locally. Unchecked steps remain unverified.
